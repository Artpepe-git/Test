# УчительPRO — браузерная версия

Одна страница `index.html` без сервера: кейсы, прохождение, разбор по шагам и мастер-классы.
Результаты студента хранятся в `localStorage` его браузера и никуда не отправляются.

Открывается по постоянной ссылке GitHub Pages: **https://artpepe-git.github.io/Test/pro/**
QR-код на эту ссылку страница рисует сама — вкладка «QR».

## Пересборка после правки кейсов

Данные берутся из рабочей папки Flask-версии (`uchitelpro/app/cases/*.json`, `uchitelpro/app/mk/*.json`),
поэтому после правки кейса достаточно пересобрать страницу:

```
python3 pro/build.py
```

## Что внутри

| Файл | Что это |
| --- | --- |
| `index.html` | собранная страница — её и отдаёт GitHub Pages |
| `build.py` | сборщик: вшивает кейсы, мастер-классы и скрипты в одну страницу |
| `engine.js` | движок кейсов — перенос `app/engine.py` (шкалы, флаги, роутеры, оценка выборов) |
| `qr.js` | генератор QR-кода, без внешних библиотек |
| `src/style.css`, `src/app.js` | оформление и интерфейс |

## Отличия от версии с сервером

- Нет входа по ролям, общей базы и портфолио: каждый результат живёт на своём устройстве.
- Мастер-класс для преподавателей закрыт кодом `ПЕДАГОГ` (код лежит в коде страницы — это напоминание, а не защита).
- Нет конструктора кейсов, журнала группы и печатной версии кейса «Тетрадь».
