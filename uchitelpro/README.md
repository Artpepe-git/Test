# УчительPRO — локальное приложение (MVP)

Платформа тренировки педагогических ситуаций: ветвящиеся кейсы с оценкой, XP/значки, волонтёрство, полевые заметки, портфолио.
Работает **полностью локально**: Python + Flask + SQLite, без интернета, сервер слушает только 127.0.0.1.

## Запуск
    pip install -r requirements.txt     # нужен только Flask
    python run.py                       # откроется браузер: http://127.0.0.1:8765
    python run.py --data D:\UchitelPRO  # своя папка данных (по умолчанию %LOCALAPPDATA%\UchitelPRO или ~/.uchitelpro)

Тесты: `python -m unittest discover -s tests -v`

| Роль | Логин | Пароль |
|---|---|---|
| Студент | student1 / student2 | stud123 |

| Методист | methodist | method123 |

## Роли
- **Студент**: кейсы (зачёт / тренировка с подсказками), разбор, профиль компетенций, XP/уровни/значки, волонтёрские смены, полевые заметки, печатное портфолио с контрольным кодом.
- **Преподаватель**: группы, назначение кейсов, результаты студентов, подтверждение волонтёрских смен (даёт XP), экспорт CSV.
- **Методист**: библиотека кейсов, редактор графа (JSON) с проверкой и расчётом лучшего пути, версии, аналитика выборов, проверка заметок и превращение их в черновики кейсов.
- **Администратор**: пользователи (создание, импорт списком, сброс пароля), группы, контейнеры графики, резервные копии, журнал.

## Сценарии (ветвление с состоянием, как в визуальных новеллах)
1. «Конфликт на уроке: тетрадь над головой» — 34 узла, 8 концовок, ~18 тыс. различных прохождений, максимум 41 балл.
2. «Разговор с родителем» — 19 узлов, 6 концовок, максимум 32 балла.

Как это устроено: «выбор → последствие → выбор». Каждое решение меняет скрытые **шкалы** (например, доверие Артёма и Лизы, климат в классе) и запоминает **флаги** («узнали про чат», «пообещали тайну»). От состояния зависят:
- что дети расскажут (скрытая информация открывается только при доверии);
- какие варианты доступны (закрытые показываются с подсказкой, что нужно выяснить);
- невидимые переходы и отложенный эпилог («через неделю»), где аукаются прежние решения.

В зачётной попытке шкалы скрыты, их показывает разбор после прохождения; в тренировке они видны сразу. Оценка шага считается **в его контексте**: один и тот же ответ может быть оптимальным в одном состоянии и слабым в другом.

Оценка: каждый выбор даёт баллы по 5 компетенциям (COM, EMP, TAC, ETH, REF), финал добавляет бонус. Движок точно считает лучший путь перебором состояний (узел, шкалы, флаги); по нему вычисляются доля баллов, звёзды (при неудаче не больше 1, при частичном результате не больше 2) и рейтинг каждого шага. 100 % по компетенции — столько же баллов, сколько на золотом пути.

XP: за зачётную попытку `(30 + 50·доля) · (0,8 + 0,2·сложность)`; повторы ×0,5, затем ×0,25; не более 300 XP в сутки за кейсы; тренировка XP не даёт. Волонтёрство: 15 XP/час, до 90 за смену, после подтверждения преподавателем. Заметка: +30 XP при принятии, +60 при превращении в кейс. Уровень L начинается с 50·L·(L−1) XP.

## Графика: контейнеры
Все фоны и персонажи — заглушки. Готовый файл кладётся в `<папка данных>/assets/…` (или загружается в разделе «Графика»):
- `backgrounds/<сцена>.png` — classroom, classroom_after, corridor, office;
- `characters/<id>.png` — artem, liza, irina, student_a; варианты настроения: `liza_sad.png`, `artem_angry.png`;
- `ui/mascot.png`, `ui/logo.png`.
Список слотов строится автоматически по опубликованным кейсам.

## Свои кейсы
«Методист → Кейсы → Создать черновик». Формат — в `app/cases/*.json`; описание условий, шкал и флагов — в начале `app/engine.py`. Редактор сразу показывает недостижимые финалы, тупики и зацикливания. Встроенные кейсы при обновлении программы публикуются новой версией. Публикация создаёт новую версию; начатые попытки остаются на своей версии.

## Сборка в .exe (Windows)
    pip install pyinstaller
    pyinstaller --noconfirm --onedir --add-data "app/templates;app/templates" --add-data "app/static;app/static" --add-data "app/cases;app/cases" run.py
Данные хранятся вне папки программы, обновление не затрагивает базу. Сборка не проверялась (в среде разработки нет Windows).

## Безопасность
Пароли — scrypt; CSRF-токены на всех формах; блокировка входа после 5 неудач на 5 минут; временные пароли показываются один раз и требуют смены; права проверяются на сервере; чужие данные возвращают 404.

## Доступ с любого устройства через GitHub Codespaces + QR-код

Проект лежит в папке `uchitelpro/` репозитория, настройка Codespaces — в `.devcontainer/` в корне.

1. На странице репозитория: **Code → Codespaces → Create codespace on main**.
2. Codespace сам поставит зависимости, запустит сайт, откроет порт и напечатает в терминале **ссылку и QR-код**.
   Те же QR сохраняются в `uchitelpro/qr.svg` и `uchitelpro/qr.png` — можно вывести на экран или распечатать.
3. Наведите камеру телефона на QR — сайт откроется с любого устройства.

Важно:
- Ссылка работает, пока codespace запущен (после ~30 мин простоя засыпает; запустите снова — ссылка та же, база сохраняется).
- Бесплатный лимит GitHub — около 60 часов в месяц на личный аккаунт.
- Если порт не стал публичным: вкладка «Порты» → правый клик по 8765 → «Видимость порта» → Public. Без этого телефон попросит вход в GitHub.
- Перезапуск вручную: `bash uchitelpro/scripts/codespace_start.sh`.
- Данные (база) лежат в `~/.uchitelpro` внутри codespace и не попадают в репозиторий.
